# Legacy examples

The pinned extraction source
`00748e6ac7b65f50e5c2af07f6e7c1c535c7f4c0` contains twelve active TTTv2
model examples and no example classified as obsolete or legacy. Consequently,
there is no frozen legacy payload in the initial standalone snapshot.

Future obsolete examples must move here rather than be deleted. Each legacy
directory must retain its final README, support manifest, constraints, model
revision, software versions, hardware topology, last validation evidence, and
the release/tag where it was supported. Legacy examples are preserved for
reproduction but are excluded from current support claims and default CI.
